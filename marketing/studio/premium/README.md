# Valorin brand posts: premium white report style

Cards and videos for brand posts (service posts, CFO Desk, article cut-downs). The look matches the
Peppol Pulse design locked on 21 Oct 2026 (`tools/`): white page, ivory diagonal top right, the logo with
"Finance with Integrity. Growth with Insight." under it, the navy contact footer, the Roboto fonts and the
George voice. Team decision, 23 Oct 2026: brand posts use this style. The older dark studio (`../build.py`)
is kept for reference only.

This folder is a copy adapted for brand content. Never edit `tools/`, `media/`, `data/` or `CLAUDE.md`
(those belong to the Peppol Pulse).

## Set up (fresh workspace)

    bash marketing/studio/premium/setup.sh

## Post file: `posts/<id>.json`

```json
{
  "id": "2026-10-23-fractional-cfo-board",
  "date": "2026-10-23",
  "card": {
    "kicker": "FRACTIONAL CFO · 23 OCT 2026",
    "head": "One question as the headline",
    "sub": "One line of context",
    "figure": {"n": "9", "unit": "MONTHS", "label": "what the figure means. <b>Bold the takeaway.</b>"},
    "tiles": [{"k": "LABEL", "t": "Short title", "l": "One line", "alert": false}],
    "cta": {"h": "LABEL", "d": "One line", "go": "WhatsApp 058-2754282"},
    "source": "Source, publication date, checked date. General information only, not legal or tax advice. Independence line where the FTA or MoF appears."
  },
  "video": {
    "scenes": [
      {"type": "hook", "kicker": "FRACTIONAL CFO · 23 OCT 2026", "head": "Headline with <em>gold words</em>", "sub": "optional", "say": "Voiceover for this scene."},
      {"type": "figure", "kicker": "LABEL", "n": "9", "unit": "MONTHS", "desc": "what it means", "src": "source line", "say": "..."},
      {"type": "points", "items": [{"k": "LABEL", "n": "Short title", "l": "one line"}], "say": "..."},
      {"type": "steps", "kicker": "HOW VALORIN HELPS", "items": [{"t": "Step", "small": "detail"}], "say": "..."},
      {"type": "cta", "h": "LABEL", "b": "advisory@valorin.ae", "a": "WhatsApp 058-2754282", "disc": "General information only, not legal or tax advice. ...", "say": "..."}
    ]
  }
}
```

Rules for the content:
- Kicker: the series label from file 06 section 2 in capitals (a design treatment), then the date.
- Card headlines and captions are written in sentence case. Use a non-breaking hyphen (U+2011) in words
  such as "full‑time" so a headline never breaks at the hyphen.
- One figure per card, with its source and check date in the source line.
- Numbers in `say` are written as spoken ("nine months", "thirtieth of September, twenty twenty-seven").
  Keep the whole script to about 90–130 words (45–60 seconds at speed 0.85).
- The last scene's `say` ends with "General information only, not legal or tax advice."

## Build

    cd marketing/studio/premium
    D=../../<YYYY-MM-DD>-<post-id>; mkdir -p $D
    node render.js posts/<id>.json $D/card.png feed            # 1080x1350: LinkedIn, Facebook
    node render.js posts/<id>.json $D/card-pinterest.png pinterest   # 1080x1620: Pinterest
    node render.js posts/<id>.json $D/card-landscape.png landscape   # 1440x1080: Google Business Profile
    node render.js posts/<id>.json $D/card-x.png wide          # 1600x900: X (manual)
    node video.js  posts/<id>.json $D/video.mp4 $D/captions.srt     # 1080x1920: Instagram Reel, TikTok, YouTube Short

Both scripts print a WARNING if text overflows; shorten the text and rebuild. Look at every card and a few
video frames (`ffmpeg -ss <s> -i video.mp4 -frames:v 1 f.png`) before posting. The video prints the scene
start times; use a time inside the hook scene (after about 2 s) for `videoCoverMilliseconds`.

Voice: Kokoro-82M (Apache 2.0), voice bm_george, speed 0.85, en-gb. Music: original, generated by
audio.py. Videos with this voice carry the AI-generated flags on Instagram, YouTube and TikTok.
