# Valorin brand marketing media

Separate from the Peppol Pulse (which uses media/, data/ and tools/; don't change those).

- `studio/`: card and video builder (`bash studio/setup.sh`, then `python3 studio/build.py studio/posts/<id>.json`).
- `<YYYY-MM-DD>-<post-id>/`: finished, public media for one brand post (card.png, vertical.png, video.mp4, captions.srt).
- Metricool media URL: `https://raw.githubusercontent.com/valorin1a/valorin-media/main/marketing/<folder>/<file>`

Rules live in the Claude project "Valorin Marketing" (knowledge pack and files 01–07). Only finished, public files here. No credentials, account IDs or client data.
